NEXTLAB – Mini-Webseitenprojekt

Du erstellst eine kleine Website mit drei HTML-Seiten und einer gemeinsamen CSS-Datei.

Projektstruktur:
W05_Starter_NEXTLAB/
├─ bilder/
│  ├─ nextlab.png
│  ├─ robotik.png
│  └─ mobilitaet.png
├─ css/
│  └─ style.css
└─ seiten/
   └─ (hier entstehen robotik.html und mobilitaet.html)

Erstelle zusätzlich im Hauptordner index.html.

PHASE 1 – FUNKTIONIERENDE WEBSITE
1. Erstelle index.html sowie seiten/robotik.html und seiten/mobilitaet.html.
2. Nutze jeweils ! + Enter für das HTML-Grundgerüst.
3. Binde die gemeinsame CSS-Datei korrekt ein.
4. Navigation auf jeder Seite: Startseite | Robotik | E-Mobilität.
5. Bilder mit korrekten relativen Pfaden und sinnvollen alt-Texten.
6. Mindestens eine class mehrfach und mindestens eine id gezielt einsetzen.
7. Auf einer Unterseite einen externen Link zu einer seriösen Quelle ergänzen.

PHASE 2 – BOXMODELL-UPGRADE
Nutze:
- max-width
- margin
- padding
- border
- background-color
- border-radius
- .karte
- .navigation
- .projektbild

RECHERCHE
Recherchiere box-sizing: border-box. Erkläre in einem Satz die Wirkung.

PFLICHTTEXTE

Startseite
NEXTLAB
Technik entdecken. Ideen entwickeln. Zukunft gestalten.
NEXTLAB zeigt zwei technische Zukunftsfelder: Robotik und E-Mobilität.
Wähle ein Thema aus und entdecke die Grundlagen.

Robotik
Roboter verbinden Mechanik, Elektronik und Informatik.
Sensoren erfassen ihre Umgebung, Programme werten Informationen aus und Aktoren führen Bewegungen aus.
Beispiel: Ein mobiler Roboter erkennt mit Sensoren ein Hindernis und ändert selbstständig seine Fahrtrichtung.

E-Mobilität
Elektromobilität verbindet elektrische Antriebe, Energiespeicher und digitale Steuerung.
Elektromotoren arbeiten effizient und stellen ihr Drehmoment sehr schnell zur Verfügung.
Eine zentrale Herausforderung bleibt die intelligente Speicherung und Bereitstellung elektrischer Energie.
